## Employee Database Using SQL

##  Project Overview

This project focuses on creating and analyzing an **Employee Database using SQL**. The project demonstrates how SQL can be used to store, manage, retrieve, and analyze employee information efficiently.

##  Tools & Technologies

* MySQL
* SQL
* MySQL Workbench

##  Database Operations

The project includes:

* Creating an employee database and table
* Inserting employee records
* Retrieving employee information
* Filtering data using `WHERE`
* Sorting data using `ORDER BY`
* Removing duplicate results using `DISTINCT`
* Using aliases with `AS`
* Performing aggregate functions such as `COUNT()`, `SUM()`, `AVG()`, `MIN()`, and `MAX()`
* Grouping data using `GROUP BY`
* Filtering grouped data using `HAVING`
* Using subqueries
* Finding the highest and second-highest salaries
* Comparing employee salaries with department averages

## Key Analysis

The project analyzes employee information such as:

* Employee names
* Departments
* Salaries
* Department-wise salary statistics
* Highest and second-highest salaries
* Employees earning above their department average
